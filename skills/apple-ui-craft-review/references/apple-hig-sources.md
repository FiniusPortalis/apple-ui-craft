## Developer documentation to open as needed

Use official framework documentation to verify API names, deployment availability, and semantics. Common starting points:

- SwiftUI: https://developer.apple.com/documentation/swiftui
- UIKit: https://developer.apple.com/documentation/uikit
- AppKit: https://developer.apple.com/documentation/appkit
- Accessibility: https://developer.apple.com/documentation/accessibility
- Accessibility Inspector: https://developer.apple.com/documentation/accessibility/accessibility-inspector
- XCTest: https://developer.apple.com/documentation/xctest

Do not assume an API exists merely because it sounds plausible. Verify its declaration and availability against the repository's deployment targets.
